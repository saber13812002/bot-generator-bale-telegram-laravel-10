# دستورالعمل تست سیستم دعوت

این فایل شامل دستورالعمل‌های تست سیستم دعوت ربات قرآن است.

## تست‌های SQL

فایل `test_referral_system.sql` را اجرا کنید:

```bash
mysql -u [username] -p [database_name] < database/sql_tests/test_referral_system.sql
```

یا در phpMyAdmin/MySQL Workbench:
1. فایل را باز کنید
2. کوئری‌ها را یکی یکی اجرا کنید

## تست‌های دستورات ربات

### تست 1: پردازش `/start` با پارامتر دعوت

**مراحل:**
1. یک کاربر را به عنوان دعوت‌کننده در نظر بگیرید (مثلاً chat_id: `123456789`)
2. لینک دعوت را بسازید: `https://t.me/[bot_username]?start=123456789` یا `https://ble.ir/[bot_username]?start=123456789`
3. از یک حساب دیگر روی لینک کلیک کنید
4. دستور `/start` باید به صورت خودکار با پارامتر ارسال شود
5. بررسی کنید که `invited_by` در دیتابیس ذخیره شده باشد:

```sql
SELECT chat_id, invited_by, created_at 
FROM bot_users 
WHERE invited_by = '123456789'
ORDER BY created_at DESC;
```

**نتیجه مورد انتظار:**
- کاربر جدید باید در `bot_users` ثبت شود
- فیلد `invited_by` باید برابر با `123456789` باشد

### تست 2: دستور `/invite`

**مراحل:**
1. به ربات دستور `/invite` یا `/دعوت` بفرستید
2. بررسی کنید که:
   - پیام دعوت نمایش داده شود
   - لینک دعوت نمایش داده شود
   - دکمه "رونوشت لینک اختصاصی" نمایش داده شود
   - اگر دعوت‌شده‌ای دارید، آمار دعوت‌شدگان نمایش داده شود

**نتیجه مورد انتظار:**
- پیام دعوت باید شامل آیه و توضیحات باشد
- لینک دعوت باید به فرمت `https://t.me/[bot_username]?start=[chat_id]` یا `https://ble.ir/[bot_username]?start=[chat_id]` باشد
- دکمه باید قابل کلیک باشد

### تست 3: بررسی آمار دعوت‌شدگان

**مراحل:**
1. یک کاربر را دعوت کنید (از طریق لینک دعوت)
2. کاربر دعوت‌شده باید چند آیه بخواند (دستور `/sure1ayah1` و غیره)
3. دستور `/invite` را دوباره بزنید
4. بررسی کنید که آمار دعوت‌شدگان نمایش داده شود

**نتیجه مورد انتظار:**
- باید پیام "طی ۷ روز گذشته شما و X فرد دعوت‌شده توسط شما، مجموعاً Y آیه رو قرائت کرده‌اید." نمایش داده شود
- X باید تعداد دعوت‌شدگان فعال باشد
- Y باید مجموع آیات خوانده شده باشد

### تست 4: بررسی آمار روزانه

**مراحل:**
1. در Laravel Tinker اجرا کنید:

```php
$service = app(\App\Interfaces\Services\QuranBotUserRankingService::class);
$stats = $service->getDailyStatistics();
print_r($stats);
```

2. بررسی کنید که:
   - `total_ayahs` تعداد کل آیات خوانده شده در روز گذشته باشد
   - `unique_users` تعداد کاربران منحصر به فرد باشد
   - `complete_rounds` تعداد دور کامل باشد (total_ayahs / 6236)

**نتیجه مورد انتظار:**
- آمار باید با کوئری SQL تست 4 مطابقت داشته باشد

### تست 5: بررسی کش

**مراحل:**
1. در Laravel Tinker اجرا کنید:

```php
use Illuminate\Support\Facades\Cache;
use Carbon\Carbon;

$cacheKey = 'daily_quran_stats_' . Carbon::yesterday()->format('Y-m-d');
Cache::forget($cacheKey);

$service = app(\App\Interfaces\Services\QuranBotUserRankingService::class);
$stats1 = $service->getDailyStatistics(); // باید از دیتابیس بخواند
$stats2 = $service->getDailyStatistics(); // باید از کش بخواند

var_dump($stats1 == $stats2); // باید true باشد
```

**نتیجه مورد انتظار:**
- اولین فراخوانی باید از دیتابیس بخواند
- دومین فراخوانی باید از کش بخواند
- نتایج باید یکسان باشند

## تست‌های Integration

### تست کامل سناریو دعوت

1. **کاربر A** دستور `/invite` را می‌زند
2. لینک دعوت را دریافت می‌کند
3. لینک را برای **کاربر B** می‌فرستد
4. **کاربر B** روی لینک کلیک می‌کند
5. ربات باید `/start` را با پارامتر دریافت کند
6. `invited_by` باید در دیتابیس ذخیره شود
7. **کاربر B** چند آیه می‌خواند
8. **کاربر A** دوباره `/invite` می‌زند
9. باید آمار دعوت‌شدگان نمایش داده شود

## عیب‌یابی

### مشکل: لینک دعوت ساخته نمی‌شود

**بررسی:**
1. آیا bot username در دیتابیس وجود دارد؟
2. آیا token درست است؟
3. لاگ‌ها را بررسی کنید:

```php
Log::info('Invitation link generation', [
    'chat_id' => $chatId,
    'type' => $type,
    'token' => substr($token, 0, 10) . '...'
]);
```

### مشکل: `/start` با پارامتر کار نمی‌کند

**بررسی:**
1. آیا پارامتر درست استخراج می‌شود؟
2. آیا `invited_by` ذخیره می‌شود؟
3. لاگ‌ها را بررسی کنید:

```php
Log::info('Start command with referral', [
    'chat_id' => $bot->ChatID(),
    'text' => $bot->Text(),
    'referral_code' => $referralCode
]);
```

### مشکل: آمار دعوت‌شدگان نمایش داده نمی‌شود

**بررسی:**
1. آیا کاربران دعوت شده‌اند؟
2. آیا دعوت‌شدگان فعالیت داشته‌اند؟
3. کوئری SQL تست 5 را اجرا کنید

## نکات مهم

1. **کش**: آمار روزانه برای 24 ساعت کش می‌شود
2. **فقط اگر خالی باشد**: `invited_by` فقط اگر خالی باشد ذخیره می‌شود
3. **تفاوت chat_id**: referral code باید با chat_id خود کاربر متفاوت باشد
4. **REGEXP**: در برخی نسخه‌های MySQL ممکن است REGEXP کار نکند
