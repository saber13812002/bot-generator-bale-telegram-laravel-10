# تست‌های SQL برای سیستم دعوت ربات قرآن

این پوشه شامل کوئری‌های SQL و دستورات Shell برای تست و بررسی سیستم دعوت است.

## نحوه استفاده

### 1. اجرای کوئری‌های SQL

#### روش 1: از طریق MySQL CLI
```bash
mysql -u [username] -p [database_name] < referral_system_tests.sql
```

#### روش 2: از طریق phpMyAdmin یا MySQL Workbench
- فایل `referral_system_tests.sql` را باز کنید
- کوئری مورد نظر را انتخاب کنید
- اجرا کنید

#### روش 3: از طریق Laravel Tinker
```bash
php artisan tinker
```
سپس کوئری‌ها را به صورت دستی اجرا کنید.

### 2. اجرای تست‌های Shell

تست‌های Shell را می‌توانید مستقیماً در ترمینال اجرا کنید:

```bash
# بررسی تعداد لاگ‌های /start با پارامتر
php artisan tinker --execute="
\$count = \App\Models\BotLog::where('text', 'like', '/start %')
    ->where('is_command', true)
    ->whereWebhookEndpointUri('webhook-quran-word')
    ->count();
echo 'تعداد لاگ‌های /start با پارامتر: ' . \$count . PHP_EOL;
"
```

## لیست کوئری‌های موجود

### 1. بررسی لاگ‌های `/start` با پارامتر
- **هدف**: بررسی لاگ‌هایی که کاربران از طریق لینک دعوت آمده‌اند
- **نتیجه**: لیست لاگ‌ها با پارامتر استخراج شده

### 2. بررسی تعداد دعوت‌شدگان هر کاربر
- **هدف**: بررسی اینکه هر کاربر چند نفر را دعوت کرده است
- **نتیجه**: لیست دعوت‌کنندگان با تعداد دعوت‌شدگان

### 3. بررسی آمار دعوت‌شدگان فعال
- **هدف**: بررسی دعوت‌شدگانی که در 7 روز گذشته فعالیت داشته‌اند
- **نتیجه**: لیست دعوت‌کنندگان با تعداد دعوت‌شدگان فعال

### 4. بررسی آمار روز گذشته
- **هدف**: بررسی آمار کلی روز گذشته (کاربران، آیات، دور کامل)
- **نتیجه**: آمار روز گذشته

### 5. بررسی آمار هفتگی
- **هدف**: بررسی آمار 7 روز گذشته
- **نتیجه**: آمار هفتگی

### 6. بررسی آمار دعوت‌شدگان یک کاربر خاص
- **هدف**: بررسی آمار دعوت‌شدگان یک کاربر مشخص
- **نکته**: باید `@user_chat_id` را با chat_id واقعی جایگزین کنید

### 7. بررسی توزیع دعوت‌شدگان بر اساس پلتفرم
- **هدف**: بررسی اینکه دعوت‌شدگان از کدام پلتفرم (Bale/Telegram) آمده‌اند
- **نتیجه**: توزیع بر اساس پلتفرم

### 8. بررسی کاربرانی که بیشترین فعالیت را دارند
- **هدف**: پیدا کردن کاربران فعال در 7 روز گذشته
- **نتیجه**: لیست کاربران با بیشترین فعالیت

### 9. بررسی کاربرانی که از طریق لینک دعوت آمده‌اند
- **هدف**: بررسی کاربرانی که از طریق لینک دعوت ثبت‌نام کرده‌اند
- **نتیجه**: لیست کاربران با invited_by و تعداد آیات خوانده شده

## نکات مهم

1. **بررسی آمار**: کوئری‌های 3 و 4 را برای بررسی آمار استفاده کنید
2. **تست کاربر خاص**: کوئری شماره 6 را برای تست یک کاربر خاص استفاده کنید
3. **بررسی دعوت‌شدگان**: کوئری شماره 2 را برای بررسی تعداد دعوت‌شدگان هر کاربر استفاده کنید
4. **بررسی فعالیت**: کوئری شماره 8 را برای بررسی کاربران فعال استفاده کنید

## مثال استفاده

```bash
# 1. بررسی آمار روز گذشته
mysql -u root -p database_name -e "
SELECT 
    COUNT(DISTINCT chat_id) as unique_users,
    COUNT(*) as total_ayahs,
    FLOOR(COUNT(*) / 6236) as complete_rounds
FROM bot_logs 
WHERE webhook_endpoint_uri = 'webhook-quran-word'
    AND is_command = 1
    AND text REGEXP '/sure[0-9]+ayah[0-9]+'
    AND created_at >= DATE_SUB(NOW(), INTERVAL 1 DAY);
"

# 2. بررسی تعداد دعوت‌شدگان
mysql -u root -p database_name -e "
SELECT 
    invited_by,
    COUNT(*) as invitees_count
FROM bot_users 
WHERE invited_by IS NOT NULL
GROUP BY invited_by
ORDER BY invitees_count DESC
LIMIT 10;
"
```

## عیب‌یابی

اگر کوئری‌ها کار نمی‌کنند:

1. **بررسی نام جدول**: مطمئن شوید نام جدول‌ها درست است
2. **بررسی فیلدها**: مطمئن شوید فیلد `invited_by` در جدول `bot_users` وجود دارد
3. **بررسی REGEXP**: در برخی نسخه‌های MySQL ممکن است REGEXP کار نکند، از LIKE استفاده کنید
4. **بررسی تاریخ**: مطمئن شوید تاریخ‌ها درست هستند
