## 🔧 پیش‌نیازها

### 1. نصب Dependencies

```bash
composer install
```

### 2. اجرای Migrations

```bash
php artisan migrate
```

این دستور جداول زیر را ایجاد می‌کند:
- `bot_users` (با فیلدهای location)
- `weather_alerts`
- `pro_users`
- `pro_purchase_requests`
- `weather_history`

### 3. تنظیمات Environment

مطمئن شوید که در فایل `.env` این متغیرها تنظیم شده‌اند:

```env
# Weather API
TOMORROW_API_TOKEN=your_tomorrow_api_token
OPENWEATHER_API_TOKEN=your_openweather_api_token

# Pro Admin Contact
PRO_ADMIN_CONTACT=@sabertaba

# Bot Mother Tokens (برای بله)
BOT_MOTHER_TOKEN_BALE=your_bot_mother_bale_token
```

### 4. پاک کردن Cache

```bash
php artisan config:clear
php artisan cache:clear
php artisan route:clear
```

## 🤖 ساخت ربات در Bot Mother (بله)

### قدم 1: دریافت توکن ربات Bot Mother از بله

1. به [@bale_bot](https://bale.ai/bale_bot) در بله بروید
2. دستور `/newbot` را ارسال کنید
3. نام ربات را وارد کنید (مثلاً: `Bot Mother`)
4. Username ربات را وارد کنید (مثلاً: `my_bot_mother_bot`)
5. توکن ربات را کپی کنید (مثلاً: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### قدم 2: راه‌اندازی Bot Mother در بله

1. ربات Bot Mother خود را در بله باز کنید
2. دستور `/start` را ارسال کنید
3. اگر اولین بار است، ربات شما را ثبت می‌کند

### قدم 3: بررسی Webhook

مطمئن شوید که webhook برای Bot Mother در بله تنظیم شده است:

```bash
# بررسی webhook
curl "https://tapi.bale.ai/bot<YOUR_BOT_MOTHER_TOKEN>/getWebhookInfo"
```

## 🌤️ ساخت ربات هواشناسی

### قدم 1: ساخت ربات جدید در بله

1. به [@bale_bot](https://bale.ai/bale_bot) در بله بروید
2. دستور `/newbot` را ارسال کنید
3. نام ربات را وارد کنید (مثلاً: `Weather Bot`)
4. Username ربات را وارد کنید (مثلاً: `my_weather_bot`)
5. توکن ربات را کپی کنید

### قدم 2: ساخت ربات از طریق Bot Mother

1. به ربات Bot Mother در بله بروید
2. دستور `/start` را ارسال کنید
3. از منوی ربات‌ها، گزینه "ساخت ربات جدید" را انتخاب کنید
4. نوع ربات را انتخاب کنید: **"هواشناسی"** یا **"weather-bot"**
5. نوع پیام‌رسان را انتخاب کنید: **"بله"**
6. زبان را انتخاب کنید: **"فارسی"** یا **"English"**
7. توکن ربات هواشناسی را که در قدم 1 دریافت کردید ارسال کنید
8. منتظر بمانید تا ربات ساخته شود

### قدم 3: بررسی ساخت ربات

پس از ساخت، باید پیام زیر را دریافت کنید:

```
✅ ربات شما ساخته شد.
```

### قدم 4: تست دستور /start در ربات هواشناسی

1. به ربات هواشناسی خود در بله بروید
2. دستور `/start` را ارسال کنید

**نتیجه مورد انتظار:**
- اگر location تنظیم نشده باشد، باید پیام درخواست location دریافت کنید
- اگر location تنظیم شده باشد، باید پیام خوش‌آمدگویی با لیست دستورات دریافت کنید

## 📍 تست Location

### قدم 1: ارسال Location

1. در ربات هواشناسی، دستور `/location` را ارسال کنید
2. یا مستقیماً location خود را ارسال کنید:
   - روی آیکون 📎 کلیک کنید
   - "Location" را انتخاب کنید
   - موقعیت خود را ارسال کنید

**نتیجه مورد انتظار:**
```
✅ موقعیت مکانی شما با موفقیت ذخیره شد
آدرس: [آدرس شما]
```

### قدم 2: بررسی ذخیره Location در دیتابیس

```bash
php artisan tinker
```

```php
$user = \App\Models\BotUsers::where('chat_id', 'YOUR_CHAT_ID')->first();
$user->latitude;  // باید latitude شما باشد
$user->longitude; // باید longitude شما باشد
$user->location_address; // باید آدرس شما باشد
```

### قدم 3: تست دستور /start بعد از تنظیم Location

1. دستور `/start` را دوباره ارسال کنید

**نتیجه مورد انتظار:**
```
خوش آمدید!

موقعیت فعلی: [آدرس شما]

[لیست دستورات]
```

## 🌡️ تست دستورات پایه

### تست 1: دستور /current

**هدف:** دریافت وضعیت فعلی آب و هوا

**مراحل:**
1. دستور `/current` را ارسال کنید

**نتیجه مورد انتظار:**
```
وضعیت هوا 🌬 در [شهر شما]:
: [توضیحات آب و هوا]
دید و برد چشم: [عدد]
تعداد ابرها: [عدد]
دمای هوا: [عدد]
...
```

**بررسی:**
- آیا اطلاعات آب و هوا نمایش داده می‌شود؟
- آیا location شما استفاده شده است؟
- آیا دستورات در انتهای پیام نمایش داده می‌شوند؟

### تست 2: دستور /forecasting

**هدف:** دریافت پیش‌بینی باد برای 16 ساعت آینده

**مراحل:**
1. دستور `/forecasting` را ارسال کنید

**نتیجه مورد انتظار:**
- اگر بدون عدد ارسال شود، باید پیام راهنما دریافت کنید:
  ```
  لطفاً حداقل سرعت باد را برای ربات تعیین کنید...
  ```
- اگر عدد بین 1 تا 20 ارسال شود (مثلاً `10`)، باید پیش‌بینی باد برای سرعت بالای 10 کیلومتر بر ساعت نمایش داده شود

**بررسی:**
- آیا پیش‌بینی باد نمایش داده می‌شود؟
- آیا فقط ساعات با سرعت باد بالای حد تعیین شده نمایش داده می‌شوند؟


```bash

```

```php
$user = \App\Models\BotUsers::where('chat_id', 'YOUR_CHAT_ID')->first();

$alerts->count(); // باید 1 باشد
```

## 🐛 مشکلات رایج

### مشکل 1: Location ذخیره نمی‌شود

**راه‌حل:**
1. بررسی کنید که migration اجرا شده باشد:
   ```bash
   php artisan migrate:status
   ```
2. بررسی کنید که فیلدهای `latitude` و `longitude` در جدول `bot_users` وجود دارند

### مشکل 2: API Weather کار نمی‌کند

**راه‌حل:**
1. بررسی کنید که `TOMORROW_API_TOKEN` و `OPENWEATHER_API_TOKEN` در `.env` تنظیم شده‌اند
2. بررسی لاگ‌ها:
   ```bash
   tail -f storage/logs/laravel.log
   ```

### مشکل 3: Job اجرا نمی‌شود

**راه‌حل:**
1. بررسی کنید که cron job تنظیم شده باشد:
   ```bash
   * * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1
   ```
2. بررسی کنید که queue driver درست تنظیم شده باشد

### مشکل 4: Pro کار نمی‌کند

**راه‌حل:**
1. بررسی کنید که `config/pro_features.php` وجود دارد
2. بررسی کنید که `endpoint_id` در جدول `bots` درست تنظیم شده باشد
