# ✅ چک‌لیست تست دستی (رگرسیون) بعد از رفع باگ‌های تست

> این چک‌لیست همه مسیرهای واقعی ربات‌ها را پوشش می‌دهد که زیر تأثیر تغییرات قرار گرفته‌اند.
> بعد از هر تست، نتیجه را در ستون «نتیجه» (✅ / ❌ + توضیح یک خطی) بنویسید و بفرستید.
>
> **قبل از شروع:** مطمئن شوید webhook هر ربات روی سرور توسعه تنظیم است و
> `storage/logs/laravel.log` خالی (یا یک مارکر بگیرید):
> ```
> powershell -NoProfile -Command "Get-Item storage\logs\laravel.log | Select-Object Length,LastWriteTime"
> ```
> **بعد از پایان همه تست‌ها:**
> ```
> powershell -NoProfile -Command "Select-String -Path storage\logs\laravel.log -Pattern 'ERROR|Exception|SQLSTATE' | Select-Object -Last 20"
> ```
> باید هیچ خطای جدیدی نبینید (به‌خصوص خطاهای `Unknown column`).
