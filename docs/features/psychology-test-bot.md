# ربات تست روانشناسی (Psychology Test Bot)

## 📝 توضیحات

ربات تست روانشناسی یک سیستم جامع برای ایجاد و برگزاری تست‌های روانشناسی است. این ربات امکان تعریف سوالات 5 گزینه‌ای با دسته‌بندی‌ها، وزن‌ها و محاسبه امتیازات را فراهم می‌کند. این سیستم می‌تواند برای تست‌های مختلف روانشناسی مانند MBTI، تست رضایت شغلی، تست سازگاری زوجین و غیره استفاده شود.

## 🎯 اهداف

- ایجاد سیستم جامع برای تست‌های روانشناسی
- امکان تعریف سوالات با دسته‌بندی و وزن
- محاسبه دقیق امتیازات بر اساس پاسخ‌ها
- مدیریت ادمین‌ها برای مشاهده نتایج
- ذخیره تاریخچه کامل تست‌های کاربران

## 🔄 Flow کاری

### 1. ساخت ربات در ربات مادر

1. کاربر `/start` را در ربات مادر می‌زند
2. لیست endpoint ها نمایش داده می‌شود
3. کاربر endpoint "تست روانشناسی" را انتخاب می‌کند
4. نوع پیام‌رسان (Telegram/Bale) را انتخاب می‌کند
5. توکن ربات را وارد می‌کند
6. ربات ساخته می‌شود و سازنده به عنوان ادمین اضافه می‌شود
7. سیستم درخواست import سوالات می‌کند

### 2. Import سوالات

1. کاربر سوالات را به فرمت زیر وارد می‌کند:
   ```
   سوال متن سوال [دسته, وزن, جهت]
   ```
   
   مثال:
   ```
   آیا در جمع‌ها راحت هستید؟ [برون‌گرا, 1.0, 1]
   ترجیح می‌دهید تنها باشید؟ [درون‌گرا, 0.9, 1]
   ```

2. سیستم سوالات را parse می‌کند و دسته‌بندی‌های جدید را شناسایی می‌کند
3. بعد از وارد کردن "پایان"، سیستم لیست دسته‌ها را نمایش می‌دهد
4. برای هر دسته، سیستم از کاربر توضیحات می‌خواهد

### 3. استفاده از ربات

1. کاربر `/start` را در ربات تست می‌زند
2. ربات سوالات را به صورت رندوم نمایش می‌دهد
3. هر سوال با 5 گزینه (خیلی کم، کم، متوسط، زیاد، خیلی زیاد) نمایش داده می‌شود
4. بعد از پاسخ به همه سوالات، امتیازات محاسبه می‌شود
5. گزارش نهایی به کاربر نمایش داده می‌شود
6. نتیجه در دیتابیس ذخیره می‌شود

### 4. مدیریت ادمین‌ها

1. سازنده ربات می‌تواند با دستور `/add_admin chat_id` ادمین اضافه کند (تا 3 نفر)
2. ادمین‌ها می‌توانند با دستور `/results` نتایج کاربران را مشاهده کنند

## 🔧 نحوه استفاده

### 2. ساخت ربات از طریق ربات مادر

1. به ربات مادر بروید
2. دستور `/start` را ارسال کنید
3. endpoint "تست روانشناسی" را انتخاب کنید
4. توکن ربات را وارد کنید
5. سوالات را به فرمت مشخص شده وارد کنید

### 3. فرمت سوالات

هر سوال باید به فرمت زیر باشد:
```
متن سوال [نام دسته, وزن, جهت]
```

**پارامترها:**
- **نام دسته**: نام دسته‌بندی سوال (مثلاً "برون‌گرا"، "درون‌گرا")
- **وزن**: عدد بین 0 تا 1 (پیش‌فرض: 1.0) - وزن سوال در محاسبه امتیاز
- **جهت**: 0 یا 1
  - `0` = خیلی کم به سمت دسته (یعنی اگر کاربر "خیلی کم" را انتخاب کند، امتیاز به دسته داده می‌شود)
  - `1` = خیلی زیاد به سمت دسته (یعنی اگر کاربر "خیلی زیاد" را انتخاب کند، امتیاز به دسته داده می‌شود)

**مثال:**
```
آیا در جمع‌ها راحت هستید؟ [برون‌گرا, 1.0, 1]
ترجیح می‌دهید تنها باشید؟ [درون‌گرا, 0.9, 1]
```

### 4. دستورات ربات

- `/start` - شروع تست (برای کاربران)
- `/add_admin chat_id` - اضافه کردن ادمین (فقط برای سازنده)
- `/results` - مشاهده نتایج (برای ادمین‌ها)

## 📊 ساختار دیتابیس

### جدول `psychology_test_bots`
- `id`: شناسه
- `bot_id`: ارتباط با جدول `bots`
- `title`: عنوان تست
- `description`: توضیحات کلی
- `created_at`, `updated_at`

### جدول `psychology_test_categories`
- `id`: شناسه
- `psychology_test_bot_id`: ارتباط با ربات تست
- `name`: نام دسته (مثلاً "درون‌گرا/برون‌گرا")
- `description`: توضیحات دسته
- `created_at`, `updated_at`

### جدول `psychology_test_questions`
- `id`: شناسه
- `psychology_test_bot_id`: ارتباط با ربات تست
- `psychology_test_category_id`: ارتباط با دسته
- `question_text`: متن سوال
- `weight`: وزن سوال (پیش‌فرض 1.0)
- `direction`: جهت سوال (0 = خیلی کم به سمت دسته، 1 = خیلی زیاد به سمت دسته)
- `order`: ترتیب نمایش (برای رندوم کردن)
- `created_at`, `updated_at`

### جدول `psychology_test_results`
- `id`: شناسه
- `psychology_test_bot_id`: ارتباط با ربات تست
- `chat_id`: شناسه چت کاربر
- `origin`: نوع پیام‌رسان (telegram/bale)
- `result_data`: JSON شامل امتیازات هر دسته
- `completed_at`: تاریخ تکمیل تست
- `created_at`, `updated_at`

### جدول `psychology_test_bot_admins`
- `id`: شناسه
- `psychology_test_bot_id`: ارتباط با ربات تست
- `chat_id`: شناسه چت ادمین
- `origin`: نوع پیام‌رسان (telegram/bale)
- `is_creator`: آیا سازنده ربات است؟
- `created_at`, `updated_at`

## 📐 منطق محاسبه امتیاز

برای هر دسته:
1. سوالات مربوط به آن دسته را جمع‌آوری کن
2. برای هر پاسخ:
   - اگر `direction = 1`: امتیاز = (شماره گزینه - 1) / 4 * weight
   - اگر `direction = 0`: امتیاز = (4 - شماره گزینه + 1) / 4 * weight
3. مجموع امتیازات را برای دسته محاسبه کن
4. امتیاز نهایی = (مجموع امتیازات / مجموع وزن‌ها) * 100

**مثال:**
- سوال با وزن 1.0 و direction 1
- کاربر گزینه "زیاد" (شماره 4) را انتخاب می‌کند
- امتیاز = (4-1) / 4 * 1.0 = 0.75

## 🔐 Validation Rules

- وزن سوال باید بین 0 تا 1 باشد
- جهت باید 0 یا 1 باشد
- حداکثر 3 ادمین (شامل سازنده)
- هر دسته باید توضیحات داشته باشد

## 💡 مثال: تست MBTI

برای ساخت یک تست MBTI ساده، می‌توانید از 4 دسته استفاده کنید:
- برون‌گرا (E) vs درون‌گرا (I)
- حسی (S) vs شهودی (N)
- فکری (T) vs احساسی (F)
- قضاوتی (J) vs ادراکی (P)

برای هر بعد، سوالاتی تعریف کنید که کاربر را به یکی از دو طرف هدایت کند.
