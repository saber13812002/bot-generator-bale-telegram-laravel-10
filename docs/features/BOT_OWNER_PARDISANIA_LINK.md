# لینک‌دهی از pardisania.ir به bots.pardisania.ir

سایت اصلی `pardisania.ir` خارج از این ریپو است. برای اتصال صفحه اول پردیسانیا به سرویس ساخت ربات:

## URL پیشنهادی

```
https://bots.pardisania.ir/bots
```

## متن دکمه پیشنهادی

```
ساخت ربات خودتان
```

## توضیح کوتاه (اختیاری)

```
با شماره موبایل و OTP بله وارد شوید و ربات اختصاصی خود را بسازید.
```

## لینک از کاتالوگ ربات‌ها

صفحه اصلی `bots.pardisania.ir` (`/`) شامل:
- بنر CTA به `/bots`
- دکمه «+ ساختن» روی هر کارت ربات
- لینک بازگشت به `https://pardisania.ir`

## نمونه HTML

```html
<a href="https://bots.pardisania.ir/bots" class="btn-primary">
  ساخت ربات خودتان
</a>
```
