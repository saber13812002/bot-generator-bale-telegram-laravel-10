# 📋 Get Chat ID Bot - مستندات کامل

## 🎯 معرفی

ربات Get Chat ID یک ربات ساده و کاربردی است که به شما امکان می‌دهد:
- شناسه چت خود را دریافت کنید
- شناسه کانال‌ها و گروه‌ها را از پیام‌های فوروارد شده استخراج کنید
- اطلاعات کامل پیام‌های فوروارد شده را مشاهده کنید
- شناسه کاربران فوروارد کننده را ببینید

## ✨ ویژگی‌ها

### 1. دریافت شناسه چت
- نمایش شناسه چت فعلی (خصوصی، گروه، کانال)

### 2. استخراج اطلاعات پیام فوروارد شده
- **شناسه کانال/گروه**: اگر پیام از یک کانال یا گروه فوروارد شده باشد
- **شناسه کاربر فوروارد کننده**: شناسه کاربری که پیام را فوروارد کرده
- **اطلاعات ارسال‌کننده اصلی**: شناسه و نام کاربری که پیام را ابتدا ارسال کرده
- **تاریخ فوروارد**: تاریخ و زمان فوروارد شدن پیام
- **امضای فوروارد**: برای کانال‌ها (در صورت وجود)

### 3. پشتیبانی از چندین پلتفرم
- ✅ تلگرام (Telegram)
- ✅ بله (Bale)
- ✅ گپ (Gap)

## 🚀 نحوه استفاده

### استفاده مستقیم

```
POST /api/webhook-bot-get-id?origin=bale&bot_mother_id=1&token=YOUR_BOT_TOKEN&language=fa
```

### استفاده از طریق Bot Mother

1. ربات Bot Mother را باز کنید
2. دستور `/start` را ارسال کنید
3. از لیست endpoint ها، **Get Chat ID Bot** را انتخاب کنید
4. نوع ربات (تلگرام/بله) را انتخاب کنید
5. زبان را انتخاب کنید
6. توکن ربات را ارسال کنید
7. ربات آماده استفاده است!

## 🔧 تنظیمات

### Seeder

برای ثبت endpoint در Bot Mother:

```bash
php artisan db:seed --class=GetChatIdBotWebhookEndpointSeeder
```

### Route

Route در `routes/api.php`:

```php
Route::post('/webhook-bot-get-id', [BotMotherController::class, 'getIdMother']);
```

### پارامترهای Webhook

- `origin`: نوع پلتفرم (`bale`, `telegram`, `gap`)
- `bot_mother_id`: شناسه Bot Mother
- `token`: توکن ربات
- `language`: زبان (اختیاری، پیش‌فرض: `fa`)

## 📊 ساختار داده‌های استخراج شده

### از `forward_from_chat`:
- `id`: شناسه کانال/گروه
- `type`: نوع چت (`channel`, `group`, `supergroup`)
- `title`: عنوان کانال/گروه
- `username`: نام کاربری کانال/گروه

### از `forward_from`:
- `id`: شناسه کاربر
- `first_name`: نام
- `last_name`: نام خانوادگی
- `username`: نام کاربری

### از `from`:
- `id`: شناسه ارسال‌کننده پیام
- `first_name`: نام
- `last_name`: نام خانوادگی
- `username`: نام کاربری

### از `chat`:
- `id`: شناسه چت فعلی
- `type`: نوع چت
- `title`: عنوان (برای گروه/کانال)
- `username`: نام کاربری (برای چت خصوصی)

## 🔍 نکات مهم

1. **پیام فوروارد شده**: ربات فقط اطلاعات پیام‌های فوروارد شده را استخراج می‌کند. برای پیام‌های عادی، فقط شناسه چت فعلی نمایش داده می‌شود.

2. **حریم خصوصی**: برخی کاربران ممکن است تنظیمات حریم خصوصی خود را طوری تنظیم کرده باشند که اطلاعات فوروارد در دسترس نباشد.

3. **کانال‌های عمومی**: برای کانال‌های عمومی، اطلاعات بیشتری در دسترس است.

4. **گروه‌ها**: در گروه‌ها، ممکن است برخی اطلاعات محدود باشد.

## 🐛 عیب‌یابی

### مشکل: اطلاعات فوروارد نمایش داده نمی‌شود
- بررسی کنید که پیام واقعاً فوروارد شده باشد
- برخی کاربران ممکن است تنظیمات حریم خصوصی داشته باشند

### مشکل: Route پیدا نمی‌شود
- مطمئن شوید که route با `/api/` شروع می‌شود
- Cache را پاک کنید: `php artisan cache:clear`

### مشکل: Seeder اجرا نمی‌شود
- بررسی کنید که جدول `webhook_endpoints` وجود دارد
- Migration را اجرا کنید: `php artisan migrate`
