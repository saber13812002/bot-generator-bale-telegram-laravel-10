# چک لیست تست فیچرهای جدید

این چک لیست برای تست فیچرهای جدید اضافه شده به ربات مادر است.

## ✅ فیچر 1: زبان‌های جدید

### تست ساخت ربات با زبان‌های جدید

- [ ] ساخت ربات با زبان ایتالیایی (`it`)
  - [ ] انتخاب endpoint شماره 7
  - [ ] انتخاب نوع ربات (Telegram/Bale)
  - [ ] انتخاب زبان ایتالیایی از لیست
  - [ ] ارسال توکن
  - [ ] بررسی پیام موفقیت: نام زبان باید "🇮🇹 Italiano" باشد
  - [ ] بررسی webhook URL: باید شامل `language=it` باشد

- [ ] ساخت ربات با زبان اندونزیایی (`id`)
  - [ ] بررسی پیام موفقیت: نام زبان باید "🇮🇩 Bahasa Indonesia" باشد
  - [ ] بررسی webhook URL: باید شامل `language=id` باشد

- [ ] ساخت ربات با زبان سواحیلی (`sw`)
  - [ ] بررسی پیام موفقیت: نام زبان باید "🇰🇪 Kiswahili" باشد
  - [ ] بررسی webhook URL: باید شامل `language=sw` باشد

### تست نمایش نام زبان

- [ ] ساخت ربات با هر زبان موجود
- [ ] بررسی اینکه نام زبان به درستی نمایش داده می‌شود (نه فقط فارسی/انگلیسی)
- [ ] بررسی همه 18 زبان

### تست تغییر نام Endpoint

- [ ] بررسی لیست endpoint ها: endpoint شماره 7 باید "کامل قرآن مرور ختم و حفظ شماره 7" باشد
- [ ] ساخت ربات با endpoint شماره 7
- [ ] بررسی پیام موفقیت: نام endpoint باید صحیح باشد

## ✅ فیچر 2: دستور /statistics

### تست نمایش آمار کلی

- [ ] ارسال دستور `/statistics` یا `/استاتستیکس`
- [ ] بررسی نمایش "کل مشترکین"
- [ ] بررسی نمایش "استارت در 1 هفته قبل"
- [ ] بررسی نمایش "استارت در 1 ماه قبل"
- [ ] بررسی نمایش "استارت در 1 سال قبل"

### تست لیست ربات‌ها

- [ ] بررسی نمایش لیست ربات‌های ساخته شده
- [ ] برای هر ربات بررسی:
  - [ ] Bot ID
  - [ ] نام ربات
  - [ ] نوع ربات (Telegram/Bale)
  - [ ] زبان
  - [ ] Endpoint
  - [ ] تاریخ ساخت

### تست آمار ربات‌های قرآنی

- [ ] ساخت یک ربات قرآنی
- [ ] استفاده از ربات قرآنی (ارسال چند دستور)
- [ ] بررسی آمار قرآنی در `/statistics`:
  - [ ] کاربران یونیک
  - [ ] آیات خوانده شده
  - [ ] کل تعاملات

### تست با ربات‌های مختلف

- [ ] تست با ربات مادر که چندین ربات ساخته است
- [ ] تست با ربات مادر که هیچ رباتی نساخته است
- [ ] تست با ربات مادر که فقط ربات‌های قرآنی دارد
- [ ] تست با ربات مادر که ربات‌های مختلف دارد

## ✅ فیچر 3: دستور /broadcast

### تست انتخاب زبان

- [ ] ارسال دستور `/broadcast` یا `/ارسال_همگانی`
- [ ] بررسی نمایش لیست زبان‌ها با دکمه‌های inline
- [ ] انتخاب زبان از دکمه
- [ ] بررسی پیام "زبان انتخاب شد"

### تست ارسال پیام

- [ ] بعد از انتخاب زبان، ارسال یک پیام تست
- [ ] بررسی پیام "در حال ارسال پیام..."
- [ ] بررسی پیام نتیجه:
  - [ ] تعداد ارسال موفق
  - [ ] تعداد خطاها
  - [ ] لیست خطاها (اگر وجود داشته باشد)

### تست با زبان‌های مختلف

- [ ] ارسال پیام به کاربران فارسی
- [ ] ارسال پیام به کاربران انگلیسی
- [ ] ارسال پیام به زبان‌های جدید (it, id, sw)

### تست Rate Limiting

- [ ] ارسال پیام به تعداد زیادی کاربر
- [ ] بررسی اینکه ارسال به صورت تدریجی انجام می‌شود
- [ ] بررسی اینکه خطایی در API رخ نمی‌دهد

### تست مدیریت خطا

- [ ] تست با کاربری که chat_id نامعتبر دارد
- [ ] بررسی اینکه خطا ثبت می‌شود اما ارسال به سایر کاربران ادامه می‌یابد
- [ ] بررسی نمایش خطاها در نتیجه

- [ ] تست `/broadcast` وقتی هیچ کاربری با زبان انتخابی وجود ندارد
