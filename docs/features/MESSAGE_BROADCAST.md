# ارسال پیام همگانی (Broadcast)

## توضیحات

این فیچر امکان ارسال پیام به کاربران بر اساس زبان را فراهم می‌کند. با استفاده از این فیچر می‌توانید به تمام کاربرانی که با یک زبان خاص با ربات‌های شما تعامل داشته‌اند، پیام ارسال کنید.

## نحوه استفاده

### دستور `/broadcast`

1. دستور `/broadcast` یا `/ارسال_همگانی` را در ربات مادر ارسال کنید
2. زبان مورد نظر را از لیست انتخاب کنید (یا مستقیماً کد زبان را ارسال کنید)
3. پیام خود را ارسال کنید
4. سیستم به صورت خودکار پیام را به تمام کاربران با زبان انتخابی ارسال می‌کند

### مراحل ارسال

1. **انتخاب زبان**: لیست زبان‌های پشتیبانی شده نمایش داده می‌شود
2. **ارسال پیام**: بعد از انتخاب زبان، پیام خود را ارسال کنید
3. **نمایش نتایج**: بعد از اتمام ارسال، تعداد پیام‌های ارسال شده و خطاها نمایش داده می‌شود

## فایل‌های مرتبط

- `app/Services/BotMessageBroadcastService.php` - سرویس اصلی برای ارسال پیام
- `app/Http/Controllers/BotMotherController.php` - متدهای `handleBroadcastStart()`, `handleBroadcastLanguageSelection()`, `handleBroadcastMessageInput()`
- `app/Helpers/BotMotherStateHelper.php` - مدیریت state برای broadcast

## ویژگی‌ها

### Rate Limiting

برای جلوگیری از spam و محدودیت‌های API، بین هر پیام 100ms تاخیر وجود دارد.

### مدیریت خطا

- در صورت بروز خطا برای یک کاربر، خطا ثبت می‌شود اما ارسال به سایر کاربران ادامه می‌یابد
- حداکثر 5 خطای اول در گزارش نمایش داده می‌شود

### فیلترها

- **زبان**: پیام فقط به کاربرانی با زبان انتخابی ارسال می‌شود
- **نوع ربات**: پیام فقط به کاربرانی که از همان نوع ربات (Telegram/Bale) استفاده می‌کنند ارسال می‌شود
- **ربات مادر**: فقط کاربرانی که با ربات مادر مشخص شده تعامل داشته‌اند در نظر گرفته می‌شوند

## مثال استفاده

```
کاربر: /broadcast
ربات: 📢 ارسال پیام همگانی
      🌍 لطفاً زبان را انتخاب کنید:
      [دکمه‌های زبان]

کاربر: [انتخاب فارسی]
ربات: ✅ زبان انتخاب شد: 🇮🇷 فارسی
      📝 حالا لطفاً پیام خود را ارسال کنید:

کاربر: سلام! این یک پیام تست است.
ربات: ⏳ در حال ارسال پیام...
      لطفاً صبر کنید.

ربات: ✅ ارسال پیام همگانی انجام شد!
      📊 نتایج:
      • ✅ ارسال موفق: 450
      • ❌ خطا: 2
```

## متدهای Service

### `sendMessageToUsersByLanguage()`

ارسال پیام به کاربران بر اساس زبان

```php
$broadcastService = new BotMessageBroadcastService();
$result = $broadcastService->sendMessageToUsersByLanguage(
    $language,      // کد زبان (مثلاً 'fa', 'en')
    $message,       // متن پیام
    $botType,       // نوع ربات ('bale' یا 'telegram')
    $botMotherId,   // شناسه ربات مادر
    $endpointUri    // (اختیاری) فیلتر بر اساس endpoint
);
```

### `sendMessageToBotUsers()`

ارسال پیام به کاربران یک ربات خاص

```php
$result = $broadcastService->sendMessageToBotUsers(
    $botId,     // شناسه ربات
    $message,   // متن پیام
    $botType    // نوع ربات
);
```

## نکات مهم

- پیام‌ها به صورت همزمان ارسال نمی‌شوند (rate limiting)
- برای ربات‌های بزرگ، ارسال ممکن است چند دقیقه طول بکشد
- خطاها در لاگ ثبت می‌شوند
- فقط کاربرانی که حداقل یک بار با ربات تعامل داشته‌اند در لیست قرار می‌گیرند

## امنیت

- فقط ادمین‌ها می‌توانند از این فیچر استفاده کنند (بررسی در `botMotherWebhook`)
- پیام‌ها به صورت مستقیم ارسال می‌شوند (بدون ذخیره در دیتابیس)
