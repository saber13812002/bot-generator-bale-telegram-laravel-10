## 1. 🤖 Quran Bot (ربات قرآن)
**endpoint_id:** `quran-bot`

### توضیحات
ربات قرآن کریم با امکانات کامل مطالعه، حفظ، ختم و جستجو در قرآن کریم. پشتیبانی از ۱۸ زبان زنده دنیا.

### مراحل استفاده
1. `/start` را بزنید
2. یک سوره را انتخاب کنید (لیست ۱۱۴ سوره)
3. یک آیه را انتخاب کنید یا شماره آیه را بفرستید
4. گزینه‌های نمایش:
   - **متن آیه** با ترجمه فارسی/انگلیسی
   - **فایل صوتی** قرائت عربی و فارسی
   - **تفسیر** مختصر آیه
   - **کلمه به کلمه** برای آموزش
   - **صفحه اسکن شده** قرآن

### خروجی نمونه
```
📖 سوره حمد (۱)
بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِیمِ
به نام خداوند بخشنده مهربان

🔊 فایل صوتی: [پخش]
📖 ادامه: /sure1ayah2
```

### نکات
- پشتیبانی از **۱۸ زبان**: فارسی، انگلیسی، عربی، فرانسوی، اسپانیایی، ترکی، آلمانی، روسی، اردو، چینی، هندی، سواحیلی و...
- قابلیت **جستجوی پیشرفته** در کل قرآن
- سیستم **حفظ و تکرار** هوشمند
- طرح **ختم قرآن** در بازه زمانی دلخواه

## 2. 🌤️ Weather Bot (ربات هواشناسی)
**endpoint_id:** `weather-bot`

### توضیحات
ربات پیش‌بینی آب و هوا با قابلیت تنظیم هشدارهای خودکار برای تغییرات دما و سرعت باد.

### مراحل استفاده
1. `/start` را بزنید
2. نام شهر خود را بفرستید
3. ربات پیش‌بینی ۱۶ ساعته را نمایش می‌دهد
4. برای تنظیم هشدار:
   - **هشدار دما**: حداقل و حداکثر دما را تنظیم کنید
   - **هشدار باد**: سرعت باد را تنظیم کنید
   - **هشدار باران**: درصد احتمال بارش را تنظیم کنید

### خروجی نمونه
```
🌤 آب و هوای تهران
📅 امروز ۱۵ تیر ۱۴۰۵

🌡 دما: ۳۲°C (کم: ۲۵°C - زیاد: ۳۶°C)
💧 رطوبت: ۴۵%
💨 باد: ۱۲ km/h
🌧 بارش: ۱۰%

🔔 هشدار: افزایش دما به ۳۶°C در ساعت ۱۴
```

### نکات
- داده‌ها از **OpenWeatherMap** و **Tomorrow.io**
- پشتیبانی از **فارسی** و **انگلیسی**
- امکان تنظیم **هشدار برای گروه**

## 3. 📖 Hadith Bot (ربات حدیث)
**endpoint_id:** `hadith-bot`

### توضیحات
جستجو و مطالعه احادیث شیعه از کتب معتبر با قابلیت جستجوی پیشرفته.

### مراحل استفاده
1. `/start` را بزنید
2. یک کلمه یا عبارت جستجو را بفرستید
3. نتایج جستجو به ترتیب مرتبط‌ترین نمایش داده می‌شود
4. روی هر نتیجه کلیک کنید تا متن کامل حدیث با سند نمایش داده شود
5. `/random` برای حدیث تصادفی

### خروجی نمونه
```
📜 نتیجه جستجو برای "علم":
۱. امام علی (ع): طلب العلم فریضة...
۲. امام صادق (ع): العلم نور...
[برای مشاهده کامل، شماره را بفرستید]
```

### نکات
- جستجوی **فول‌تکست** در متن احادیث
- نمایش **سلسله سند**
- نمایش **تاریخچه جستجو**های کاربر

🔍 ادامه مطلب: /nahj1more
📋 فهرست: /nahjlist

## 5. 🕌 Prayer Qadha Bot (ربات نماز قضا)
**endpoint_id:** `prayer-bot`

### توضیحات
ثبت و پیگیری رکعات نماز قضا با تشخیص هوشمند نوع نماز و گزارش هفتگی ایمیلی.

### مراحل استفاده
1. `/start` را بزنید
2. تعداد رکعتی که خواندید را بفرستید (۲، ۳، ۴)
3. ربات هوشمند تشخیص می‌دهد کدام نماز را خواندید
4. برای ثبت تخمین: `/estimate`
5. برای گزارش هفتگی: ایمیل خود را ثبت کنید

### خروجی نمونه
```
🕌 ثبت شد: ۴ رکعت
✅ تشخیص: نماز ظهر
📊 مجموع: ۱۲۴ رکعت

🔢 بعدی را بفرستید یا /report برای گزارش
```

### نکات
- **تشخیص هوشمند** نوع نماز بر اساس تعداد رکعت
- **گزارش هفتگی** ایمیلی با آمار
- **صفحه وب** برای مشاهده گزارش
- **ثبت تخمین** نمازهای قضا

## 7. 📝 Content Submission Bot (ربات محتوای متنی/عکس/فیلم)
**endpoint_id:** `content-submission`

### توضیحات
دریافت محتوا (متن، عکس، ویدیو) از کاربران، ارسال به گروه تایید، انتشار در کانال.

### مراحل استفاده
1. کاربر در پیوی ربات یک متن/عکس/فیلم می‌فرستد
2. محتوا به **گروه تایید** ارسال می‌شود
3. ادمین با ریپلای `۱` تایید می‌کند
4. محتوا در **کانال** منتشر می‌شود
5. به کاربر اعلام می‌شود

### خروجی نمونه (برای ادمین)
```
📬 محتوای جدید از @user
📝 متن: سلام و عرض ادب...

✅ برای تایید ریپلای «۱» بزنید
❌ برای رد ریپلای «۲» بزنید
```

## 10. 📋 List Bot (فهرست با دکمه شیشه‌ای)
**endpoint_id:** `list-bot`

### توضیحات
ایجاد منوی درختی با دکمه‌های اینلاین شامل لینک به ربات‌ها، کانال‌ها و سایت‌ها.

### مراحل استفاده
1. پس از ساخت ربات، ساختار منو را با فرمت مخصوص وارد کنید
2. فرمت: خط اول با `-` عنوان اصلی، هر زیرمنو با `--` یا `---`
3. کاربر `/start` می‌زند و منو را می‌بیند

### فرمت منو
```
- عنوان مادر
-- زیر۱: https://t.me/bot
-- زیر۲: لینک کانال
--- زیر۲-۱: https://site.com
```

## 📸 راهنمای تصاویر

برای هر ربات می‌توانید یک تصویر در مسیر زیر قرار دهید:

```
public/images/bots/{endpoint_id}.png
```

مثال:
```
public/images/bots/quran-bot.png
public/images/bots/weather-bot.png
public/images/bots/mawkib-finder.png
```

**اندازه پیشنهادی:** ۸۰۰x۴۰۰ پیکسل  
**فرمت:** PNG  
**نام:** دقیقاً برابر `endpoint_id` با پسوند `.png`

تصاویر را در گیت commit کنید تا در سایت نمایش داده شوند.
