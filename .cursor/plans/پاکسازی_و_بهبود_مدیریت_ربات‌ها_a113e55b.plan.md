# پاکسازی و بهبود مدیریت ربات‌ها

## مشکلات و نیازمندی‌ها

1. **پاک کردن رکوردهای خالی**: رکوردهایی در جدول `bots` وجود دارند که اطلاعات کافی ندارند
2. **جلوگیری از تعریف ربات‌های خالی**: باید validation اضافه شود تا ربات‌های ناقص ثبت نشوند
3. **اضافه کردن bot_id به webhook URL**: هنگام ثبت webhook، `bot_id` باید در URL قرار گیرد تا در لاگ‌ها قابل شناسایی باشد
4. **دستور re-register**: یک دستور Artisan برای re-register کردن همه ربات‌های موجود با webhook جدید که شامل `bot_id` است

## راه حل‌ها

### 1. پاک کردن رکوردهای خالی از جدول bots

**فایل**: `app/Console/Commands/CleanEmptyBots.php` (جدید)

**معیارهای رکورد خالی**:

- رباتی که نه `telegram_bot_token` دارد و نه `bale_bot_token`
- رباتی که `telegram_bot_token` دارد اما `telegram_bot_name` ندارد
- رباتی که `bale_bot_token` دارد اما `bale_bot_name` ندارد
- رباتی که `bot_mother_id` ندارد یا 0 است (به جز ربات مادر که id=1 است)

**تغییرات**:

- ساخت یک Artisan command برای پاک کردن رکوردهای خالی
- نمایش لیست ربات‌هایی که پاک می‌شوند
- امکان dry-run برای بررسی قبل از پاک کردن

### 2. جلوگیری از تعریف ربات‌های خالی

**فایل**: `app/Http/Controllers/BotMotherController.php`

**تغییرات**:

- در متد `handleTokenInput`، قبل از `save()` بررسی کنیم که:
  - اگر `botType == 'telegram'`، باید `telegram_bot_token` و `telegram_bot_name` وجود داشته باشد
  - اگر `botType == 'bale'`، باید `bale_bot_token` و `bale_bot_name` وجود داشته باشد
  - `bot_mother_id` باید وجود داشته باشد و بزرگتر از 0 باشد
- اگر این شرایط برقرار نبود، ربات را ذخیره نکنیم و پیام خطا بدهیم

### 3. اضافه کردن bot_id به webhook URL

**فایل**: `app/Helpers/WebhookEndpointHelper.php`

**تغییرات**:

- در متد `createWebhookUrl`، بعد از اینکه `botItem->save()` شد و `id` داشت، `bot_id` را به پارامترهای URL اضافه کنیم
- `bot_id` باید همیشه در URL باشد (حتی اگر ربات جدید است)

**مثال**:

```php
// قبل:
$params['token'] = $token;
$params['bot_mother_id'] = $botMotherId;
$params['language'] = $language;
$params['origin'] = $type;

// بعد:
$params['token'] = $token;
$params['bot_mother_id'] = $botMotherId;
$params['language'] = $language;
$params['origin'] = $type;
$params['bot_id'] = $botItem->id; // اضافه کردن bot_id
```

**نکته**: باید مطمئن شویم که `botItem->id` وجود دارد. اگر ربات جدید است، باید ابتدا `save()` کنیم تا `id` تولید شود.

### 4. دستور re-register برای همه ربات‌ها

**فایل**: `app/Console/Commands/ReRegisterAllBots.php` (جدید)

**عملکرد**:

- دریافت همه ربات‌های فعال از جدول `bots`
- برای هر ربات:
  - تشخیص `type` (telegram/bale)
  - دریافت `webhook_endpoint_uri` از `BotLog` (آخرین لاگ)
  - دریافت `language` از `BotLog`
  - ساخت webhook URL جدید با `bot_id`
  - فراخوانی `setWebhook` با URL جدید
  - بررسی و لاگ نتیجه

**تغییرات**:

- استفاده از `WebhookEndpointHelper::createWebhookUrl` برای ساخت URL
- اضافه کردن `bot_id` به URL
- نمایش progress bar برای ربات‌های زیاد
- لاگ کردن موفقیت/شکست هر ربات

## فایل‌های تغییر یافته

1. `app/Console/Commands/CleanEmptyBots.php` - دستور پاک کردن رکوردهای خالی (جدید)
2. `app/Http/Controllers/BotMotherController.php` - اضافه کردن validation برای جلوگیری از ربات‌های خالی
3. `app/Helpers/WebhookEndpointHelper.php` - اضافه کردن `bot_id` به webhook URL
4. `app/Console/Commands/ReRegisterAllBots.php` - دستور re-register همه ربات‌ها (جدید)

## تست‌ها

1. تست دستور `php artisan bots:clean-empty` برای پاک کردن رکوردهای خالی
2. تست ساخت ربات جدید و اطمینان از اینکه ربات‌های خالی ثبت نمی‌شوند
3. تست ساخت webhook URL و اطمینان از اینکه `bot_id` در URL است
4. تست دستور `php artisan bots:re-register` برای re-register کردن همه ربات‌ها
