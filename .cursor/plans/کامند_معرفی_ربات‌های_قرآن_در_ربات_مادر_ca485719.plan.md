# کامند معرفی ربات‌های قرآن در ربات مادر

## خلاصه

اضافه کردن یک کامند جدید به ربات مادر که متن معرفی ربات‌های قرآن را با توجه به زبان انتخابی ادمین ارسال می‌کند. این فیچر به صورت یک کلاس Service قابل استفاده مجدد پیاده‌سازی می‌شود.

## فایل‌های مرتبط

- `app/Http/Controllers/BotMotherController.php` - اضافه کردن کامند جدید
- `app/Services/QuranBotsIntroductionService.php` - کلاس Service جدید
- `config/quran_bots.php` - فایل کانفیگ ربات‌های قرآن
- `app/Helpers/BotMotherStateHelper.php` - مدیریت state برای انتخاب زبان و منبع
- `lang/{locale}/bot.php` - اضافه کردن کلیدهای ترجمه

## مراحل پیاده‌سازی

### 1. ایجاد فایل کانفیگ ربات‌های قرآن

**فایل:** `config/quran_bots.php`

این فایل شامل:

- متن معرفی به زبان فارسی (برای ترجمه به زبان‌های دیگر)
- لیست ربات‌های قرآن با مشخصات:
  - نام زبان
  - کد زبان
  - لینک ربات (Telegram)
  - توضیحات (اختیاری)
- لینک‌های کانال‌های اطلاع‌رسانی (ایتا، بله، تلگرام)

### 2. ایجاد کلاس Service

**فایل:** `app/Services/QuranBotsIntroductionService.php`

این کلاس شامل متدهای:

- `getBotsFromConfig()` - دریافت ربات‌ها از کانفیگ
- `getBotsFromDatabase($botMotherId, $type)` - دریافت ربات‌های قرآن از دیتابیس
- `mergeBots($configBots, $dbBots)` - ترکیب ربات‌های کانفیگ و دیتابیس
- `generateIntroductionMessage($language, $source = 'both')` - تولید متن معرفی
- `formatBotList($bots, $language)` - فرمت کردن لیست ربات‌ها (هر زبان در یک خط)

**نکات مهم:**

- هر ربات در یک خط جداگانه نمایش داده می‌شود
- تعداد ربات‌ها به صورت داینامیک محاسبه می‌شود
- متن با توجه به زبان انتخابی ترجمه می‌شود
- از سیستم ترجمه Laravel استفاده می‌شود

### 3. اضافه کردن کامند به ربات مادر

**فایل:** `app/Http/Controllers/BotMotherController.php`

**کامند:** `/quran_bots` یا `/ربات_قرآن` یا `ربات قرآن`

**جریان کار:**

1. کاربر کامند را ارسال می‌کند
2. از کاربر پرسیده می‌شود: "برای چه زبانی می‌خواهید متن را ببینید؟"
3. کاربر زبان را انتخاب می‌کند (از لیست زبان‌های پشتیبانی شده)
4. از کاربر پرسیده می‌شود: "از چه منبعی استفاده کنیم؟"

   - گزینه 1: ترکیب کانفیگ + دیتابیس
   - گزینه 2: فقط دیتابیس

5. متن معرفی تولید و ارسال می‌شود

**State Management:**

- `STATE_WAITING_QURAN_BOTS_LANGUAGE` - منتظر انتخاب زبان
- `STATE_WAITING_QURAN_BOTS_SOURCE` - منتظر انتخاب منبع

### 4. اضافه کردن کلیدهای ترجمه

**فایل‌ها:** `lang/{locale}/bot.php`

کلیدهای جدید:

- `quran_bots.intro.title`
- `quran_bots.intro.body`
- `quran_bots.intro.bots_intro`
- `quran_bots.intro.bots_title`
- `quran_bots.intro.channels_intro`
- `quran_bots.select_language`
- `quran_bots.select_source`
- `quran_bots.source.both`
- `quran_bots.source.database_only`
- `quran_bots.language_name.{language_code}`

### 5. دریافت ربات‌ها از دیتابیس

**منطق:**

- جستجو در جدول `bots` برای ربات‌هایی که `webhook_endpoint_uri = 'webhook-quran-word'`
- دریافت زبان از `bot_logs` برای هر ربات
- ساخت لینک از `telegram_bot_name` یا `bale_bot_name`
- فیلتر بر اساس `bot_mother_id` و `type`

### 6. به‌روزرسانی Help Message

**فایل:** `app/Http/Controllers/BotMotherController.php`

اضافه کردن کامند جدید به لیست دستورات در متد `sendHelpMessage()`.

## ساختار کلاس Service

```php
class QuranBotsIntroductionService
{
    public function getBotsFromConfig(): array
    public function getBotsFromDatabase(int $botMotherId, string $type): array
    public function mergeBots(array $configBots, array $dbBots): array
    public function generateIntroductionMessage(string $language, string $source = 'both', ?int $botMotherId = null, ?string $type = null): string
    public function formatBotList(array $bots, string $language): string
    private function getLanguageDisplayName(string $languageCode, string $targetLanguage): string
    private function buildBotLink(string $username, string $type = 'telegram'): string
}
```
