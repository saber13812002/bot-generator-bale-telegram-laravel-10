# قوانین مستندسازی فیچرها (Documentation Rule)

> **قانون قطعی و مهم:**
> از این به بعد همیشه برای هر فیچر جدید باید مستندات ایجاد کنیم یا اگر از قبل مستنداتی دارد، آن را به‌روزرسانی کنیم.

## 1. نحوه مستندسازی:
- ایجاد یا ویرایش یک فایل README اختصاصی برای فیچر (معمولاً در پوشه `docs/features/`).
- نوشتن یک لیست قدم‌به‌قدم برای **سناریوی تست (Test Scenario)** در فایل مستندات، تا مالک پروژه بتواند دقیقاً همان مراحل را طی کند و ویژگی را تحویل بگیرد.
- اضافه کردن یا ارجاع دادن این مستندات به `docs/BOTS_COMPLETE_GUIDE.md` یا `docs/TEST_SCENARIO.md` در صورت لزوم.

**هیچ فیچری بدون آپدیت مستندات کامل و سناریوی تست، بسته یا تحویل داده نمی‌شود.**
