# سناریوی تست زنده — همگام‌سازی چندکاناله (ژپتو)

این سناریو دقیقاً همان چرخه‌ای است که مأموریت می‌خواهد: **لینک یک پیام منتشرشده + متن → انتشار در کانال‌های مجاز دیگر + ثبت نسخه‌ها در دیتابیس + آماده‌بودن برای لینک بعدی، بدون سؤال اضافه.**

## پیش‌نیازها

1. محیط با `.env` واقعی (توکن بله/تلگرام ربات + کانال‌های وصل‌شده).
2. اجرای مهاجرت:
   ```
   php artisan migrate
   ```
3. ربات ژپتو در حالتی باشد که owner (شما) آن را کنترل می‌کند.
4. حداقل **دو** کانال متصل با **یک تگ مشترک** (مثلاً `tag1`) روی پلتفرم‌های متفاوت؛ مثلاً:
   - بله: `@stackoverflow_com` (chat_id عددی)
   - تلگرام: `@saberblog`
   - (اختیاری) ایتا: `alirezamehran_3`

## چک‌لیست گام‌به‌گام

### مرحله ۱ — چرخه‌ی اصلی (fast mode)

| # | عمل شما | خروجی مورد انتظار |
|---|---------|-------------------|

| 2 | متن کامل مطلب را در پیام بعدی بفرستید | بلافاصله انتشار در بله و تلگرام (کانال ایتا به‌عنوان مبدأ **مستثنی** است) + گزارش جزئی: هدر، خط مبدأ، `📊 شناسه مشترک مطلب`، برای هر مقصد یک خط با آیکون (✅/⏳/❌/⏭/⛔) و دلیل 📌، لینک‌های 🔗 فقط نسخه‌های منتشرشده، `آماده لینک بعدی.` و فوتر `📖 راهنمای دستورات: /help` |

### مرحله ۲ — تأیید ثبت در دیتابیس

```sql
SELECT * FROM content_sync_contents WHERE id = 1;
SELECT platform, publish_status, message_id, post_url, link_status, published_at
FROM content_sync_versions WHERE content_id = 1;
SELECT platform, success, message_id, post_url, link_status, content_id
FROM channel_poster_publish_logs WHERE content_id = 1;
SELECT operation, result, attempted_at FROM content_sync_operations WHERE content_id = 1;
```

مورد انتظار:
- ۳ نسخه (eitaa=`existing_source` با `post_url`+`message_id` اصل، bale=`published`/constructed، telegram=`published`/confirmed)
- `post_url` هر نسخه دقیقاً همان لینکی باشد که می‌توانید باز کنید
- ۲ رکورد در publish_logs (بale + تلگرام) با `content_id=1`
- عملیات: `register` → `attach_text` → `publish`

## معیار قبولی (Acceptance)

> با وارد کردن یک لینک و سپس یک متن، مطلب در کانال‌های مجاز دیگر منتشر شود، نسخه‌های متناظر در دیتابیس (با `post_url` و `link_status`) ثبت شوند و ربات بدون سؤال اضافه آماده لینک بعدی باشد.

## خروجی‌های کمکی

- `php artisan content-sync:report 1` — گزارش CSV/متنی یک مطلب
- `php artisan content-sync:report --all` — خروجی CSV همه‌ی مطالب (مهدمیت مهاجرت ۵۰۰۰ مطلب قدیمی)
