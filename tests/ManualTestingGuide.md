# راهنمای تست دستی - یکپارچه‌سازی فرآیند ساخت ربات
## Manual Testing Guide - Unified Bot Creation Workflow

---

## 🎯 سناریوهای تست

### سناریو 1: مسیر Bot Mother (چت تلگرام/بله)

#### 1.1 تست شروع فرآیند
1. Webhook جدید را روی ربات مادر تنظیم کنید:
   ```
   POST /api/webhook-bot-mother-v2
   ```
2. به ربات مادر `/start` بزنید
3. **انتظار:** لیست endpoint ها نمایش داده شود

#### 1.2 تست انتخاب endpoint
1. شماره یک endpoint را ارسال کنید
2. **انتظار:** اولین step ویزارد نمایش داده شود

#### 1.3 تست انتخاب platform
1. در step اول، ۱ (تلگرام) یا ۲ (بله) را ارسال کنید
2. **انتظار:** step بعدی (زبان) نمایش داده شود

#### 1.4 تست انتخاب زبان
1. شماره زبان را ارسال کنید یا روی دکمه شیشه‌ای کلیک کنید
2. **انتظار:** step توکن نمایش داده شود

#### 1.5 تست توکن نامعتبر
1. یک توکن نامعتبر ارسال کنید (مثلاً `abc`)
2. **انتظار:** پیام خطا و تکرار step

#### 1.6 تست توکن معتبر
1. یک توکن معتبر از BotFather دریافت کنید
2. توکن را ارسال کنید
3. **انتظار:** ربات با موفقیت ساخته شود و پیام تأیید نمایش داده شود

#### 1.7 تست callback query (دکمه شیشه‌ای)
1. در step انتخاب platform، روی دکمه شیشه‌ای کلیک کنید
2. **انتظار:** مثل ارسال متن عمل کند

#### 1.8 تست endpoint با ویزارد اضافی (presenter-bot)
1. endpoint presenter-bot را انتخاب کنید
2. platform و زبان و توکن را وارد کنید
3. **انتظار:** step جمع‌آوری محتوا نمایش داده شود
4. چند متن ارسال کنید و "پایان" را بزنید
5. **انتظار:** ربات ساخته شود و محتوا ذخیره شود

---

### سناریو 2: مسیر پنل وب (Bot Owner Web Panel)

#### 2.1 تست احراز هویت
1. به صفحه `/bots` بروید
2. روی "ورود" کلیک کنید
3. شماره تلفن بله را وارد کنید و OTP را دریافت کنید
4. کد را وارد کنید
5. **انتظار:** به داشبورد هدایت شوید

#### 2.2 تست ارتقا به Pro
1. در داشبورد، روی "درخواست Pro" کلیک کنید
2. از طریق Nova ادمین درخواست را تأیید کند
3. **انتظار:** وضعیت Pro فعال شود

#### 2.3 تست فرم ویزارد (endpoint ساده)
1. روی یک endpoint ساده (مثلاً quran-bot) کلیک کنید
2. فرم چندمرحله‌ای را کامل کنید
3. **انتظار:** steps به ترتیب نمایش داده شوند
4. دکمه "قبلی" و "بعدی" کار کند

#### 2.4 تست ارسال فرم
1. تمام steps را پر کنید
2. روی "ساخت ربات" کلیک کنید
3. **انتظار:** به داشبورد هدایت شوید و ربات جدید در لیست نمایش داده شود

#### 2.5 تست اعتبارسنجی
1. فیلد token را خالی بگذارید
2. **انتظار:** خطای اعتبارسنجی نمایش داده شود

#### 2.6 تست endpoint با فیلدهای شرطی
1. endpoint content-submission را انتخاب کنید
2. در step "نیاز به تایید گروه"، "بله" را انتخاب کنید
3. **انتظار:** فیلد group_id نمایش داده شود
4. برگردید و "خیر" را انتخاب کنید
5. **انتظار:** فیلد group_id پنهان شود

---

### سناریو 3: یکسان‌سازی رفتار

#### 3.1 تست خروجی یکسان
1. یک ربات یکسان (مثلاً quran-bot با platform=telegram, language=fa) از هر دو مسیر بسازید
2. **انتظار:** ربات‌های ساخته شده در دیتابیس یکسان باشند (فقط bot_owner_id متفاوت)

#### 3.2 تست محتوای ویزارد یکسان
1. برای presenter-bot، از مسیر چت محتوا وارد کنید
2. از مسیر وب هم محتوای یکسان وارد کنید
3. **انتظار:** PresenterBot.record در دیتابیس یکسان باشد

## 🛠️ دستورات تست

```bash
# اجرای مایگریشن‌های جدید
php artisan migrate

# اجرای سیدر wizard steps
php artisan db:seed --class=BotCreationWizardStepsSeeder

# پاک کردن cache
php artisan cache:clear
php artisan route:clear
php artisan config:clear

# اجرای تست‌های واحد
php artisan test tests/Unit/BotCreationWorkflowServiceTest.php

# اجرای تست‌های یکپارچه‌سازی
php artisan test tests/Feature/BotCreationWorkflowIntegrationTest.php

# اجرای همه تست‌ها
php artisan test
```
